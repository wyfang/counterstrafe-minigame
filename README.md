# CS2 Movement Trainer

在浏览器中单独训练 CS2 急停、微移动与射击节奏的轻量小游戏。

[在线试玩](http://csgo.link/web/CS2-MOVEMENT-TRAINER) · [上游项目](https://github.com/crankyCS2/counterstrafe-minigame)

## 本分支

- 完整简体中文界面
- 浅色主题与视觉调整
- 保留 Freestyle、TTK、Strafe Lab、Micro-Strafe 与 Rhythm 模式
- 使用本地统计反馈移动时机、首发精度与击杀用时

## 开始

需要 Node.js 与 npm：

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```
